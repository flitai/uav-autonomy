# G5 实体显示模块

T06 将本目录与已合格的 T03 地图、T05 状态源代码构建为同一个 Cesium 包，避免重复加载引擎。入口及实际资格见 [T06 报告](../../docs/g5-entities-validation.md)。不直接在原地图目录安装依赖或覆盖旧候选。

选用用户提供的 AFSIM UCAV 原件；1 源单位＝1 显示米，保留原点。原件前向 −Y、上向 +Z，转换为 glTF 前向 +Z、上向 +Y，再由 Cesium 完成引擎轴修正。其显示尺寸与类型不改变后端飞行／传感器性能。

中文实体列表支持选择、定位、跟随、复位以及实体／标签／实际轨迹开关。`+` 或 `=` 放大、`-` 缩小、`0` 恢复 1×，范围 0.25～32×，每步 √2；输入控件和组合快捷键不触发。倍率作用于所有显示实体，刷新恢复默认。

模型采用荧光阵营色替换原渲染颜色，避免深色材质把标识变暗；2 像素深色轮廓、选中后 3 像素白色轮廓。标签、远处点标记、列表和轨迹同色，并提供文字图例。红方红、蓝方青蓝、中立绿、未知黄；颜色与别名配置在 config/g5-entities.json。优先使用真实 EntityConfiguration.Affiliation；后端 Unknown／缺失时采用用户显示指定：400／500 蓝方、600 红方，详情注明来源，不修改原消息。未配置的其他阵营名称保留原名并使用未知色，可在配置扩展，不猜测友敌。

只接收 G4 v1 消息；ID、时间和序号保持字符串。使用后端时间减 1 秒作为插值目标，夹在实际已收到的样本区间，暂停时保持显示时间，不用墙钟外推。轨迹复用 T05 的 10 分钟／2048 样本上限，快照不伪造历史。完成不删除实体，删除／新运行／恢复清理对象及跟随引用。详情同时标明源状态时间和显示时间。

当前合格区域内，实体 MSL 按已冻结 EGM96 网格改正一次得到 WGS84 椭球高。未知高度基准和越界位置明确拒绝；数值转换误差不是原始 DEM 精度。完整任务／航线／区域图层归 T07，恢复矩阵归 T08，阶段发布归 T11。
