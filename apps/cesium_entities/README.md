# G5 实体显示模块

T06 将本目录与已合格的 T03 地图、T05 状态源代码构建为同一个 Cesium 包，避免重复加载引擎。入口及实际资格见 [T06 报告](../../docs/g5-entities-validation.md)。不直接在原地图目录安装依赖或覆盖旧候选。

选用用户提供的 AFSIM UCAV 原件；1 源单位＝1 显示米，保留原点。原件前向 −Y、上向 +Z，转换为 glTF 前向 +Z、上向 +Y，再由 Cesium 完成引擎轴修正。其显示尺寸与类型不改变后端飞行／传感器性能。

中文实体列表支持选择、定位、跟随、复位以及实体／标签／实际轨迹开关。页面按固定屏幕尺寸展示三维模型：默认包围直径 96 CSS px，实际轮廓随姿态变化；`+` 或 `=` 放大、`-` 缩小、`0` 恢复默认，范围 48～384 px，每步 √2。输入控件和组合快捷键不触发，倍率作用于所有实体，刷新恢复默认。拉近／拉远和暂停时移动镜头均保持尺寸，不替换成点；仅为显示，不代表实际占地。

模型采用银灰金属预览材质：按真实网格法线计算 GGX 高光，金属度 0.92、粗糙度 0.30，保留原面板／舱盖纹理细节；解析展示环境产生天空／地面和柔光反射，不依赖外部环境贴图。光源相对观察视角固定，不代表仿真太阳或真实传感器成像。原 GLB／纹理不改动，共享着色器随实体层释放。机体不再染阵营色；阵营色描边普通 1 像素、选中 1.5 像素，选中时保留阵营颜色。标签、列表和轨迹同阵营色并有文字图例。红方红、蓝方青蓝、中立绿、未知黄；颜色与别名配置在 config/g5-entities.json。优先使用真实 EntityConfiguration.Affiliation；后端 Unknown／缺失时采用用户显示指定：400／500 蓝方、600 红方，详情注明来源，不修改原消息。其他未配置名称保留原名并使用未知色，不猜测友敌。

只接收 G4 v1 消息；ID、时间和序号保持字符串。后端时间是唯一权威；模型使用约 1 秒缓冲，每帧在已收到的位置／姿态样本间插值。单调本地时间仅按后端倍率平滑推进显示游标，收包抖动用有限速率修正，不跳到新时间；绝不超过已收样本。暂停立即保持当前显示，缓冲耗尽停止，连接恢复／新运行清空游标。长帧最多消费 100 毫秒本地间隔，避免切回页面时突然追赶。轨迹复用 T05 的 10 分钟／2048 样本上限，快照不伪造历史；轨迹重建和详情更新最多约每 250 毫秒一次（消息／操作到达时另行更新）。完成不删除实体，删除／新运行／恢复清理对象及跟随引用。详情同时标明源状态时间和显示时间，底部仍显示后端时间。

跟随相机在实体插值之后、模型与标签可视化之前更新至同一帧 ENU 原点，保留用户的局部旋转与缩放；不等待轨迹等异步几何的包围球就绪。固定屏幕尺寸由这台已同步的相机计算，避免近距离回拉和尺寸跳变。轨迹位置采用有界缓存及动态折线，更新时不反复提交静态几何重建。真实浏览器检查包括 384 px、相机距离小于 50 米、旋转后跟随，检查最终屏幕锚点、实际模型尺寸与相机局部偏移；单纯世界坐标连续不足以证明跟随平滑。

当前合格区域内，实体 MSL 按已冻结 EGM96 网格改正一次得到 WGS84 椭球高。未知高度基准和越界位置明确拒绝；数值转换误差不是原始 DEM 精度。完整任务／航线／区域图层归 T07，恢复矩阵归 T08，阶段发布归 T11。
