# 侦察覆盖显示

组合已合格 T07 页面，新增两个独立开关，默认都显示。当前传感器覆盖来自同一 G4 连接的 CameraState.Footprint，使用阵营色并贴同源地形；原角点零高程不是地面高度。原生足迹仍为 AMASE 局部平面近似，不宣称逐角点三维遮挡计算。越界足迹只裁剪显示范围，明确提示；累计统计用原足迹判断合格任务采样点。

按用户最新明确的操作偏好：左键拖动平移，右键拖动环绕，滚轮缩放；左键点击仍选择目标。自由视角采用 Cesium 地图平移与倾斜／环绕，跟随视角的左键沿屏幕平面移动相机、右键绕跟随实体转动，平移不解除跟随。中键、触控和 Ctrl／Shift 组合手势保持原有映射；实体面板显示提示，销毁时释放输入监听。

累计覆盖由只读工作线程按运行身份、持久事件顺序及摘要重建，采用正式分析的 20 米栅格、波段、GSD 与飞机位置最近邻 DTED；点任务按同传感器相邻有效样本合并观察时间。线为采样线段、区域为已覆盖栅格、点为观察标记；没有在任务外涂抹航迹冒充合格侦察。当前只资格化零 DwellTime 及点／线／矩形任务，未知输入明确拒绝。

新增只读 `/api/coverage/v1/snapshot`，不更改 G4 v1 快照／增量或控制接口。快照绑定本次 runId，后台持续累计，开关不影响计算，刷新和晚加入恢复；新运行从新事件库重建。断流清理旧显示，服务不可用隐藏旧累计结果并提示，后台独立运行。数据库以 mode=ro／query_only 读取，无后台消息发送，无新监听端口。

累计最多 50000 单元、128 任务／实体、8 MiB 响应；区域仅合并相邻已覆盖显示格，统计计数不变。网关启动到事件库就绪之间最多等待 30 秒；已开始消费后的故障、来源失配或摘要损坏立即拒绝。构建、真实验收及联合入口见 scripts/windows/*g5-coverage* 和 tests/windows/g5-coverage.tests.ps1。资格独立绑定 T07，旧源码、候选和正式发布指针保持。
