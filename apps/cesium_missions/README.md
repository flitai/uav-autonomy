# G5-T07 航线、任务与区域

独立组合模块，复用已合格 T03 地图、T05 唯一只读连接与 T06 实体／高度转换。构建脚本在候选副本中生成三个明确的连接／初始化／销毁接点；冻结源码和旧资格保持，接点转换自身计入 T07 来源，不暴露仿真控制或生产夹具接口。

完整规划和当前分段命令分别展示，按航点字符串编号及 NextWaypoint 连线，支持非顺序编号、自环及分支。动作命令只显示后端已有接收证据。当前执行要求实体状态的命令、航点、时间与网关证据匹配，且目标存在于当前命令；启动过渡中的缺失目标保持未确认。航段还要求同命令内容内先后观察到两个相邻目标航点，时间必须前进，不根据规划、位置靠近、任务完成或快照推断已飞航段。刷新／恢复清除观察历史；当前目标仍可由新快照显示。TaskComplete 只标为后端报告完成，不删除对象或停飞。

Location3D 按 MSL／EGM96 或 AGL 转换；AGL 使用 T04 由 T02 标准化栅格直接派生的 orthometric.f32，再加一次 N96。区域／矩形边界是二维，忽略原顶点高度；地面搜索区域贴同源地形，KeepIn／KeepOut 则逐点计算上下界与墙面。矩形角点按正式 AMASE 球面导航规则生成，旋转正向从北向东；几何上限和缺失／越界／无效高度显式拒绝，不以零值代替。Padding 只显示原声明，不擅自修改边界；StartTime／EndTime 保留字符串，不假定 UTC 或仿真时间。OperatingRegion 仅引用允许／禁入区，不伪造新边界。

五组图层、航点开关、列表分页、关联实体筛选、场景选择、属性／航点查询、定位及关联对象跳转使用中文界面。派生对象和缓存随删除、新流和销毁清理；显示顶点预算 50000，单条航线不静默截断。区域和删除若来自独立协议夹具，验收与真实场景分开记录。T08 完整恢复、T09／T10 全程及规模、T11 正式发布另行实施。

销毁释放选中监听和业务集合，兼容地图已经销毁 Viewer 的顺序，禁止在该状态下访问 trackedEntity 或相机。只读诊断入口 `__g5Missions.inspect()` 不提供业务写入；正式包通过本地源码与前置资格清单复查，不包含测试注入服务。

当前 Intel／ANGLE D3D11 下，MSAA=4 在模型缩小后出现旧轮廓遮罩残留现象，冻结的 T06 包同样复现。组合页面使用 Cesium 公开的 msaaSamples=1 加 FXAA，保持原 1／1.5 像素阵营描边；不改引擎、驱动或系统设置。真实验收继续保留 T06 原像素检查和缩放上下限循环，记录实际渲染器，不能只根据显卡型号推断通过。
