# Cesium 只读状态模块

G5-T05 的 TypeScript 协议、原子状态归约、连接与中文状态面板。构建入口将本模块与已验收 T03 地图生产包组成新的候选，保留地图源码和历史收据；不修改网关 v1 协议，不通过 HTTP 快照拼接 WS 增量。

业务缓存每集合最多 4096 对象、合计 32 MiB，单包 8 MiB；轨迹最多 128 个实体，每实体 2048 点／10 分钟。快照只恢复当前业务状态，轨迹从新连接的增量重新积累；完整规划单独保留。失配或断线立即清空业务与轨迹，界面仅保留标为过期的最后时间。渲染、模型轴向和插值由 T06 接入。

标准入口及本轮证据见 [T05 报告](../../docs/g5-state-validation.md)。
