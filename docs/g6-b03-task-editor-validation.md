## 实现范围

- `apps/cesium_tasks/panel.ts` 在 Cesium 页面提供中文点、折线、矩形任务面板。可在地图取点或数值编辑几何，选择 B01 合格候选实体，保存、复制、删除草稿，调用 B02 隔离预览并显示返回航线。刷新后从服务端恢复草稿及其预览。矩形宽高、折线点数和区域边界由页面先行检查，服务端再次验证。
- `apps/g6_drafts/server.py` 在本地 `127.0.0.1:8003` 提供版本化 `/api/tasks/v1/catalog`、`/drafts`、`/operations/{key}` 及草稿创建、更新、复制、删除、预览接口。草稿和操作收据存于本次运行目录；修改需要预期修订，操作使用幂等键。保存草稿仅生成数据；预览把当前已保存修订交给 B02 的 8002 隔离服务，没有确认下发路由。严格核查 B01 任务契约、候选实体、EPSG:5773 高度基准、活动运行身份、本地 Origin 和请求大小。
- `scripts/g6_drafts/build_viewer.py` 从 G6-A 正式页面生成独立 B03 候选，绑定 G6-A 正式包、B02 合格收据和当前输入哈希；`session.py` 启动真实 AMASE、UxAS、G4、G6-A 页面和 B02／B03 服务，并在本次运行结束时清理。未覆盖 G6-A 正式包。
