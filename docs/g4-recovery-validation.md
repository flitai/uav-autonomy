## 实现与范围

网关按本次清单绑定 AMASE／UxAS 的 PID 和进程创建时间、主链路 TCP 连接、日志文件身份和初始摘要。两路观察连接断开时暂停发布，保留每次连接的原始字节和残包，使用新解析器重新接入；从已提交日志重建并核对持久事件，再以新 stream_id 发布快照。补齐仅表示语义恢复，不填造原 TCP 缺口。

持久事件库位于本次后端运行目录，独立于网关进程实例；重新启动网关仍核查同一份不可变清单，按分片／行号核对事件内容并去重。日志被替换、截断、损坏，后端进程变化或主链路断开时明确降级，接口返回 503，不在线恢复后端任务。HTTP 端口先独占绑定，再启动观察工作线程，端口冲突不能打开第二个事件库写入者。

连接接收队列、关键事件待核对集合、发布队列和内存连接摘要都有上限，完整原始记录及规范化事件保存在磁盘。暂停状态允许消息静默；运行中数据过期保留旧对象，通过 health 的新鲜度和 ready 表达，不当作删除或任务完成。

源码入口为 `src/sim_bridge/gateway.py`、`journal.py`、`windows.py` 和 `apps/gis_gateway/server.py`；独立编排与故障代理在 `scripts/g4_recovery/`、`tests/g4_recovery/`。故障代理只用于验收，产品 HTTP 不提供断线、任务或停止后端的接口。
