## 显示规则

- 模型默认包围直径为 96 CSS 像素，按相机投影和实体距离动态换算显示缩放。拉近、拉远以及暂停后移动镜头均保持屏幕尺寸，实际轮廓随姿态／投影角度变化；不保证机体边缘观察时具有相同面积。
- `+`／`=` 放大、`-` 缩小，步长 √2，范围 48～384 像素；`0` 恢复 96 像素，刷新恢复默认。尺寸作用于全部实体，输入控件与组合快捷键不触发。
- 移除远距离点符号。实体继续使用原三维网格、真实位置、姿态和深度关系；被地球／地形遮挡不表示替换成点。屏幕符号不代表真实占地，不能用放大后的模型尺寸判断净空、碰撞或统计。
- 资产仍按用户原定 1 源单位＝1 米转换，原 OSGB、GLB 字节及几何／法线／纹理保持。此次动态倍率属于显示层，不改变后端。

## 光照及来源

前版 `ColorBlendMode.REPLACE` 在光照计算后覆盖最终颜色，导致模型看起来像平面色块。本轮共享一个着色器，按真实网格法线和观察方向计算主光、补光及高光，再用 `HIGHLIGHT` 叠加阵营色。着色器使用 UNLIT 通道输出自己计算的光照，防止引擎再次叠加太阳光，并非取消表面明暗。它是相对观察视角的展示补光，不模拟太阳时刻、地面投影或真实光学效果。

蓝方青蓝、红方红、中立绿、未知黄；用户指定 400／500 蓝方、600 红方，后端明确阵营优先的规则保持。普通 2 像素深色边缘，选中 3 像素白色边缘；轨迹／标签／列表继续同色。

实现位于 [display.ts](../apps/cesium_entities/display.ts)、[layer.ts](../apps/cesium_entities/layer.ts)、[main.ts](../apps/cesium_entities/main.ts)，运行配置由 [manage.py](../scripts/g5_entities/manage.py) 生成；参数见 [g5-entities.json](../config/g5-entities.json)。着色器随实体层释放，恢复／删除不积累每实体着色器资源。

已核对锁定 Cesium 1.145.0 源码的投影、颜色及着色阶段；公开接口参考 [ModelGraphics](https://cesium.com/learn/cesiumjs/ref-doc/ModelGraphics.html)、[CustomShader](https://cesium.com/learn/cesiumjs/ref-doc/CustomShader.html)。CustomShader 是实验接口，依赖继续锁定；升级时需要重新运行真实渲染回归。
